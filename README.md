# StayNest

StayNest is an Airbnb-inspired property rental platform built using Node.js, Express.js, MySQL, and EJS.

## Features

- Create, update, and delete property listings
- Browse available properties
- MySQL database integration
- RESTful routing
- MVC architecture
- Responsive UI

## Tech Stack

- Node.js
- Express.js
- MySQL
- EJS
- HTML
- CSS

## Installation

```bash
git clone <repository-url>
cd StayNest
npm install
```

Create a `.env` file:

```env
DB_HOST=localhost
DB_USER=your_username
DB_PASSWORD=your_password
DB_NAME=staynest
PORT=3000
```

Run the application:

```bash
npm start
```
